# 토픽 수(k) 선정 시각자료

과거 LDA 실험의 그래프와 pyLDAvis 화면 캡처를 보관합니다.

| 파일 | 내용 |
| --- | --- |
| [coherence_k2-6.png](coherence_k2-6.png), [perplexity_k2-6.png](perplexity_k2-6.png) | 한국어 k 비교 그래프 (기존 파일명 유지) |
| [k10_pyLDAvis.png](k10_pyLDAvis.png) | 한국어 k=10 비교 화면 |
| [coherence_en.png](coherence_en.png), [perplexity_en.png](perplexity_en.png) | 영어 k 비교 그래프 |
| [k7_pyLDAvis_en.png](k7_pyLDAvis_en.png) | 영어 k=7 비교 화면 |

최종 노트북 설정은 한국어 k=7, 영어 k=9로 위 비교 캡처의 k와 다릅니다.
현재 노트북의 k 탐색 범위는 2~15이며 파일명만으로 실행 범위를 단정하지 않습니다.
그래프 재생성 환경과 해석은 [토픽 모델링 안내](../topic_modeling/README.md)를 참고하세요.
이미지 보관 폴더이므로 별도 requirements는 필요 없습니다.
