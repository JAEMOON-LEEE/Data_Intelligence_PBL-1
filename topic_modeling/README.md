# 토픽 모델링

전처리가 끝난 데이터로 LDA 토픽 모델링을 수행하는 코드를 정리한 문서입니다.

- 노트북: `Topic_Modeling_ko.ipynb`, `Topic_Modeling_en.ipynb` (레포 최상위 폴더)
- 라이브러리: Gensim (`LdaModel`, `CoherenceModel`), pyLDAvis
- 코드 구성: 수업 실습 7-2 노트북의 셀 순서를 따름
- 언어별로 모델을 따로 학습함 (한국어 k=7, 영어 k=9)
- k 선정 그래프와 pyLDAvis 캡처: `k초기값 시각자료/`

## 입력 데이터

| 언어 | 파일 | 문서 수 | 그룹 | `tokens` 형식 | 읽는 방법 |
| --- | --- | --- | --- | --- | --- |
| 한국어 | `data/processed/ko/processed_ko.csv` | 1,086 | bts, 세븐틴, 트와이스, 블랙핑크, 베이비몬스터, 코르티스 | JSON 리스트 (`["힘", "시기", ...]`) | `json.loads` |
| 영어 | `data/processed/en/processed_en.csv` | 800 | bts, 블랙핑크, 세븐틴, 트와이스 | 공백 구분 문자열 | `.str.split()` |

- 불용어는 전처리 단계의 결과를 그대로 사용 (그룹명 제거, 멤버명은 전처리 팀 판단에 따라 유지)
- 영어 데이터에는 세븐틴·트와이스가 그룹당 200건 포함되어 있음

## 진행 순서

| 셀 | 내용 | 비고 |
| --- | --- | --- |
| 0 | 데이터 불러오기, `tokens`를 단어 리스트로 변환 | 결측 `tokens` 행 제거 |
| 1 | `Dictionary` 생성 → `filter_extremes` → `doc2bow`로 corpus 생성 | |
| 2 | `LdaModel` 학습 | `passes=5` |
| 3 | `print_topics`로 토픽별 상위 단어 확인 | |
| 4 | `get_document_topics`로 문서별 토픽 분포 확인 | |
| 5 | pyLDAvis 시각화 | |
| 6 | `CoherenceModel`(u_mass)로 응집도 계산 | 최종 모델 |
| 7 | matplotlib 불러오기 | |
| 8 | `show_coherence`로 k별 혼란도·응집도 비교 | |
| 9 | 문서별 토픽 확률에 `group` 열을 붙임 | `minimum_probability=0` |
| 10 | `groupby('group').mean()`으로 그룹별 평균 비중 | |
| 11 | 노이즈 토픽 제외 후 비중 재계산, 토픽 라벨 붙이기 | 남은 토픽 합이 1이 되도록 나눔 |
| 12–13 | 그룹별 문서 수, `published_at` 최소·최대 | |
| 14 | 그룹별 토픽 비중 막대그래프 | |
| 15 | 한국어·영어 공통 카테고리로 묶기 | 두 모델의 토픽 번호가 달라서 사용 |
| 16–17 | 토픽별 대표 문서(확률 상위 3개) 출력 | 라벨 검증용 |

`show_coherence`는 `passes`를 지정하지 않는다. 최종 모델은 `passes=5`로 다시 학습한다. 그래서 셀 6의 응집도와 셀 8의 같은 k 응집도는 숫자가 다르다.

## 토픽 수(k) 선정

- 혼란도는 작을수록, 응집도는 클수록 좋다고 판단함 (gensim의 `log_perplexity`는 로그 값이라 클수록 좋음)
- 교재 기준에 따라 수치와 함께 토픽 해석이 자연스러운지를 같이 확인함

### 한국어: k = 7

- 응집도: k=2~3이 가장 높지만 그룹 간 비교에 쓰기에는 토픽이 너무 뭉뚱그려짐. k=6 이후 구간에서는 7이 첫 번째 봉우리 (k=6 −3.363, k=7 −2.892, k=8 −3.488)
- pyLDAvis: k=10에서는 토픽 여러 쌍이 거의 겹침
- 저장 파일: `coherence_k2-6.png`, `perplexity_k2-6.png`, `k10_pyLDAvis.png`

### 영어: k = 9

- 응집도 최댓값은 k=2 (−1.009). 그다음 봉우리는 k=9 (−1.024). 이웃인 k=8은 −1.047, k=10은 −1.075
- 혼란도는 k가 커질수록 단조 감소 (k=2 −7.756, k=15 −8.336)
- 그룹 비교에 쓰도록 최종 모델은 k=9. 최종 모델(`passes=5`)의 u_mass는 −1.559
- 저장 파일: `coherence_en.png`, `perplexity_en.png`
- `k7_pyLDAvis_en.png`는 비교 과정에서 남긴 k=7 화면이다. 원 7개가 보이며, 최종 노트북의 토픽 수는 9이다

## 토픽 라벨

- 토픽 번호는 노트북 열 이름(`Topic1` ~) 기준이다. pyLDAvis 화면의 번호와 다르다.
- 라벨은 상위 단어로 먼저 붙이고, 대표 문서(셀 16–17)를 확인해 수정했다.
- 노이즈 토픽은 모델 학습에는 포함하고, 그룹 비교에서만 제외했다.

## 한계

- 노이즈 토픽을 제외하고 비중을 다시 나눴으므로, 제외된 기사의 비중은 반영되지 않는다.
- 한국어·영어 모델은 따로 학습해서 토픽이 1:1로 대응하지 않는다. 공통 카테고리로 묶어 비교했다.
- 그룹마다 기사 수집 기간이 다르다 (BTS·블랙핑크 2017년~, 베이비몬스터 2023년~, 코르티스 2025년~).
- 신인 그룹(베이비몬스터·코르티스)은 영어 기사가 없어 한국어만 분석했다.
