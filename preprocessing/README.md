# 데이터 전처리 코드

데이터를 전처리하는 코드를 저장하는 폴더입니다.

## 전처리 방법 예시

### 공통

- 중복 데이터와 빈 본문 제거
- HTML 태그, URL, 광고 문구 등 불필요한 내용 제거
- 연속된 공백과 줄바꿈 정리

### 한국어

- 형태소 분석을 이용한 토큰화
- 분석 목적에 따라 명사, 동사, 형용사 등 추출
- 조사, 어미 등 불용어 제거
- 그룹명과 약칭 등 표기 통일

### 영어

- 소문자 변환
- 단어 단위 토큰화
- 관사, 전치사 등 불용어 제거
- 표제어 추출: 단어의 활용형을 기본형으로 변환
- 그룹명과 약칭 등 표기 통일
