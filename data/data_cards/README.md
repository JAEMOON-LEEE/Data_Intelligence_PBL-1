# 데이터 카드

데이터별 출처·기간·수집 방식·건수·필터·한계를 보관하는 문서 폴더입니다.
현재 별도 완성 카드 파일은 없습니다. 확인 가능한 설명은 다음 위치에 있습니다.

- [한국어 수집 방법과 출력](../../collection/ko/README.md)
- [영어 수집 방법 및 과거 데이터 카드](../../collection/en/README.md)
- [영어 수집 통계](../../collection/en/stats/README.md)
- [현재 CSV 건수·컬럼 차이](../README.md)

새 카드를 작성할 때는 사용한 파일, 수집일·게시일 범위, 그룹별 건수, 제외 기준,
전처리 및 모델 버전, 알려진 표본 편향을 함께 기록합니다.
문서 보관 폴더이므로 별도 실행 환경 파일은 필요 없습니다.
